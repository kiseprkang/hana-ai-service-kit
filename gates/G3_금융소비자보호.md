## 체크리스트
- [ ] 판매 대상 상품의 분류와 적용 규제 확인 [확인 필요]
- [ ] **적합성 원칙:** 고객 정보 파악 절차와 부적합 시 안내
- [ ] **적정성 원칙:** 적정성 판단 기준과 안내 문구
- [ ] **설명의무:** 핵심 설명서 제공, 중요 사항(위험·비용·해지 조건) 설명 방식
- [ ] **불공정영업행위 금지:** 특정 상품 강요, 부당 결합 판매 여부
- [ ] **부당권유 금지:** 오인 유발 표현, 불확실한 수익 단정 표현 여부
- [ ] **광고 규제:** 광고 문구의 필수 기재 사항과 심의 절차
- [ ] 위법계약해지권(청약철회 등) 안내 방식
- [ ] 고객 민원·분쟁 처리 경로 안내
- [ ] 고령·취약 고객을 위한 추가 안내 (글자 크기, 음성, 상담 연결)
