# 사내 자료 확장 폴더

나중에 사내 기준 자료를 넣는 자리입니다. 에이전트는 이 폴더를 **사내 기준**으로 참고합니다 (AGENTS.md 6번 규칙).

## 하위 폴더
| 폴더 | 넣을 자료 예시 |
|---|---|
| `규정/` | 내부통제 기준, 준법감시 규정, 정보보안 정책, AI 가이드라인 |
| `템플릿/` | 사내 기획서·보고서 양식, 승인서 양식 |
| `매뉴얼/` | 업무 매뉴얼, 대고객 서비스 운영 지침 |
| `과거사례/` | 출시 후 점검 결과, 민원 분석 요약 (개인정보 제거 후) |

## 넣기 전 확인
- 실제 고객 정보, 계좌·카드 번호, 주민등록번호가 없는지 확인하세요.
- 기밀 등급이 있는 자료는 이 키트에 넣지 마세요.
- 파일은 Git 추적에서 제외됩니다 (`.gitignore`). 이 README와 `.gitkeep`만 추적됩니다.

## 파일을 넣은 뒤
- 자료가 추가되면 이 README 아래 "등록 목록"에 파일명과 등록일을 적어 두세요. 에이전트가 목록을 먼저 확인할 수 있습니다.
