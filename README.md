# 하나원큐 AI 서비스 기획 키트 (수업용)

금융권 10년차 이상 기획자·개발자가 **AI 에이전트(Claude Code, Codex)와 함께** 대고객 서비스(앱·웹)를 기획하고, 내부 업무 프로세스와 AI 거버넌스를 점검하기 위한 **수업용 실습 키트**입니다.

> 본 키트는 교육용 가상 예시입니다. 공식 사내 표준이 아니며, 법령 조항과 사내 기준은 반드시 담당 부서의 최신 확인을 거쳐야 합니다.

벤치마킹: [rey-hailey/agent-driven-edpm](https://github.com/rey-hailey/agent-driven-edpm) (MIT) — 문서 체인, 게이트, 결정 기록, 훅 구조를 참고했습니다.

## 폴더 구조

```
hana-ai-service-kit/
├── AGENTS.md              # 에이전트 공통 규칙 (Codex, Claude Code 모두 읽음)
├── CLAUDE.md              # Claude Code 전용 설정 (AGENTS.md 가져오기)
├── README.md              # 이 파일
├── docs/                  # 산출물 체인 (순서대로 작성)
├── gates/                 # 규제·보안·내부통제 검토 게이트 7종
├── scripts/               # 검사 스크립트 (Node.js, 외부 의존성 없음)
├── .claude/               # Claude Code 훅·커스텀 명령
├── examples/              # 가상 예시 (작성 방식 참고용)
└── company-materials/     # 나중에 사내 자료를 넣는 확장 폴더 (Git 추적 제외)
```

## 시작하기

1. **Node.js 설치** (v18 이상): 설치 후 PowerShell에서 `node -v`로 확인합니다.
2. **Claude Code 또는 Codex 설치:** 각 도구의 공식 설치 문서를 따릅니다.
3. 이 폴더에서 에이전트를 실행하고 `/start-service`(Claude Code) 명령으로 과제를 시작합니다.
4. 문서를 작성한 뒤 `node scripts\check-gates.mjs`로 누락과 미검토 게이트를 확인합니다.

## 사내 자료 넣기

`company-materials/` 아래 하위 폴더(규정, 템플릿, 매뉴얼, 과거사례)에 파일을 넣으면, 에이전트가 참고 자료로 읽도록 `AGENTS.md`에 안내되어 있습니다.

**주의:** 실제 고객 정보, 내부 기밀, 미공개 정보는 수업 자료에 넣지 마세요. 이 폴더의 파일은 `.gitignore`로 Git 추적에서 제외됩니다.

## 보안 기본 규칙

- 주민등록번호, 카드번호 형식이 포함된 내용은 훅이 저장을 차단합니다 (`scripts/check-pii.mjs`).
- 예시를 쓸 때는 `900101-1******`처럼 마스킹합니다.
- 법령 조항은 확인하지 않은 경우 `[확인 필요]`로 표시합니다.
