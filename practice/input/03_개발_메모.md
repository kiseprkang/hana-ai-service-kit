# 개발팀 기술 메모 (가상)

> 교육용 가상 자료입니다.

## 기존 시스템 연계
- 잔액 조회는 기존 계좌 API를 호출합니다. 응답은 계좌별 잔액 목록입니다.
- 계좌 API 호출은 로그인 세션이 있을 때만 가능합니다.
- 응답 데이터를 DB에 저장하지 않고 화면에만 표시하는 방식을 검토 중입니다.

## 테스트 데이터 규칙
- 테스트 계좌번호는 가상 번호만 사용합니다. 실제 계좌번호를 복사해 쓰지 않습니다.
- 주민등록번호 형식의 테스트 값은 만들지 않거나 마스킹해서 씁니다. 예: `900101-1******`
- 로그에는 계좌번호 전체를 남기지 않습니다 (마스킹 규칙 적용).

## 미확인 사항
- 가족 계좌 조회 권한 확인 방식 (인증 수준)
- 잔액 갱신 주기 (실시간 조회 vs 주기적 캐시)
- 접속 로그 보관 기간
