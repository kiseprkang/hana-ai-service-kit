# 고객 인터뷰 요약 (가상 5명)

> 교육용 가상 인터뷰입니다. 실제 고객 발언이 아닙니다.

| 번호 | 가상 프로필 | 현재 불편 | 원하는 것 | 주요 발언(요약) |
|---|---|---|---|---|
| A | 50대 자영업자, 계좌 4개 | 매일 여러 앱을 번갈아 열어 잔액을 확인함 | 한 화면에서 잔액 합계 확인 | "가게 돈이 얼마인지 한눈에 알고 싶어요" |
| B | 60대 은퇴자, 스마트폰 조작 초보 | 글씨가 작고 메뉴가 복잡함 | 큰 글씨, 단순한 화면 | "버튼이 어디 있는지 몰라서 자식에게 물어봐요" |
| C | 30대 직장인, 적금 2개 | 적금 만기일과 금액을 따로 찾아야 함 | 만기와 잔액을 한눈에 확인 | "만기 날짜를 놓칠까 봐 불안해요" |
| D | 40대 맞벌이, 가족 계좌 관리 | 배우자 계좌를 확인하려면 따로 로그인해야 함 | 가족 계좌 조회 (단, 권한 명확히) | "남편 계좌도 같이 보고 싶은데 개인정보가 걱정돼요" |
| E | 20대 대학생, 계좌 2개 | 잔액을 자주 확인하지 않아 부족할 때 알림이 없음 | 간단한 잔액 알림 | "잔액이 적으면 미리 알려줬으면 좋겠어요" |

## 공통 발언 (빈도 높음)
- 계좌번호가 화면에 그대로 보이는 건 불편하다 (4명)
- 잔액이 실제와 다르면 믿기 어렵다 (3명)
- 상품을 권유받는 느낌이 들면 부담스럽다 (2명)

## 인터뷰 중 관찰
- 고령 고객은 "확인" 버튼 한 번이 더 있어도 헤매는 경우가 많았습니다.
- 가족 계좌 조회에 대해서는 모든 고객이 권한과 동의 방식을 먼저 물었습니다.
