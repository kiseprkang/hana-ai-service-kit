# 기획 팀장 메모 (가상)

> 교육용 가상 자료입니다. 실제 사내 정책이나 수치가 아닙니다.

## 요청 배경
- 하나원큐 고객들이 여러 계좌와 상품 정보를 따로 확인해야 해서 불편하다는 민원이 늘고 있습니다.
- 이번 분기에 **"나의 자산 한눈에 보기"** 기능을 R1(MVP)로 만들고 싶습니다.

## R1 범위 (합의된 내용)
- 조회 전용입니다. 이체, 상품 가입, 해지는 포함하지 않습니다.
- 계좌별 잔액과 자산 합계를 한 화면에 보여줍니다.
- 계좌번호는 앞 4자리와 뒤 4자리만 보여주고 가운데는 마스킹합니다.

## 아직 정하지 않은 것
- 상품 정보(예: 적금, 펀드)를 R1에 넣을지 여부 → 법무, 준법 검토 필요
- 자산 추천 기능(AI 활용) → R2 이후 검토
- 목표 출시 시기 → 미정

## 기대하는 결과물
- 과제 정의서, 고객 리서치, PRD, 요구사항, 기능 명세, 화면 설계, 검증 계획
- 규제 게이트(G1~G7) 검토 결과
- 결정 기록과 출시 점검표

## 주의
- 준법 부서에서 "고객에게 불리한 표현이 없는지" 꼭 확인하라고 요청했습니다.
- 개인정보는 최소한으로 수집하고, 테스트 데이터에도 실제 번호를 쓰지 않습니다.
